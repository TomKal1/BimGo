# Guide images

Screenshots and GIFs for the guide pages. Every file here starts as a **placeholder** (a dark card saying what to
capture): replace it with the real picture **under the same name** and the pages pick it up with no edits.

**Screenshots (.png):** 1280 × 720 or the window at 100 % scale, the UI visible unless the shot is about the model; crop
to the panel when the page is about a panel. PNG keeps the UI text sharp.

**GIFs (.gif):** 960 px wide (or less), 10–15 fps, 5–15 s, under ~10 MB so GitHub shows them inline. A free recorder such
as ScreenToGif can trim and resize. Keep the mouse moves slow. A file can switch between .png and .gif: rename the
file and change its link on the page.

Adding a new picture: put it here, link it from the page as `![What it shows](images/<name>.png)`, and add a row below.
