# Controls

← [Docs home](README.md)

Every key, mouse button and wheel notch is an **action**; **Esc → CONTROLS** rebinds them (up to three keys each, Shift / Ctrl / Alt combinations, mouse buttons and the wheel, a gamepad column), with a clash check that offers to swap, search, reset and keymap export / import. **F1** shows the keys for what you are doing. With a gamepad: move on the left stick, look on the right, Start is the menu; in menus the look stick moves the cursor, A clicks, B goes back; CONTROLS → MAP BUTTONS… sets up a generic controller.

The tables below are the default keys. They are generated by the Core tests (`ControlsTests.Readme_ControlsTablesAreCurrent` rewrites them when the catalogue changes): change `InputCatalog`, not the tables.

**Notes**

- **Mouse:** move to look (click the window to capture it); menus, panels and handles use the left button. **Esc** pauses, goes one level back in panels, cancels a held element and brings a hidden UI back. **U** hides the UI (errors still show).
- **Moving an element** (Gizmo / Clone / Place locked on): the move keys move it in plan (left / right turn it in rotate mode), E / Q up / down, snap steps 5 mm–1 m and 1°–90°; F drops it onto the surface below; RMB commits, Esc cancels.
- **Measure (2 again)** cycles distance → area → angle → clearance; RMB removes the last measurement, X twice clears them all.
- **Media** (Shift+M): PHOTO · TOUR · PATHS · VIDEO tabs. Bookmark tour: BOOKMARKS → PLAY TOUR. Camera paths: PATHS → NEW PATH, fly to each place, ADD KEY HERE; Shift+K opens the 3D path editor. RECORD VIDEO, sun time-lapses and batch stills are on the VIDEO / PHOTO tabs.
- **Section box (P)** has a free cursor: drag the face handles (Shift: no snap); Shift+P cuts just behind the aimed surface; Ctrl+P clears all cuts.
- **Clash detection** stays dormant until Esc → CLASHES or **Y** (clash mode: a docked list, the move keys fly, RMB-drag looks; `.` / `,` step through clashes, 1–5 set the status, G cycles the model view, B the section box, R shows the pair in Revit).
- **Photo mode (M)**, the **sun / daylight study (J)** and the **sun panel (Shift+O)** free the cursor; RMB-drag looks.
- **Undo / redo** work in files (live: undo in Revit, then F5). Screenshots (F12) and photos go to `Pictures\BimGo`, videos to `Videos\BimGo`.
